# THOCK 3D models

Procedurally generated by `generate.py` (parameters at the top of the file). Wavefront OBJ with vertex normals, no textures or UVs: the game tints by color. 1 unit = 1 stud, origin at the bottom center, +Y up, front faces -Z.

| File | Size (studs) | Triangles | Notes |
| --- | --- | --- | --- |
| `keycap.obj` | 1.0 x 0.6 x 1.0 | 336 | Cherry/OEM-style cap, 1.0 square base tapering to 0.78 at the top, rounded vertical edges, small top bevel, spherical dished top (0.07 deep). Scale per slot size. |
| `rollkey.obj` | 1.0 x 1.0 x 1.0 | 384 | Giant roll key: cap (0.45 tall, 1x1 base) on an MX "+" stem (0.40 arm length, 0.14 thick, 0.55 tall), one combined mesh. The game scales it to about 8x3x8. |
| `keyboard_case.obj` | 31.0 x 1.5 x 9.6 | 392 | 10x3 key case. Rounded outer corners and edges, 0.6 thick rim rising to y = 1.5, flat inner floor top at y = 1.1. |

All meshes are closed (watertight), consistently wound with outward normals, and have no degenerate faces (checked with trimesh).

## Regenerate and preview

```
pip install numpy trimesh matplotlib
python generate.py
python preview.py
```

Previews are written to `previews/*.png` (3/4 flat-shaded views plus extra angles, back faces culled).

## Import in Studio

1. File > Import 3D (or Asset Manager > Bulk Import) and choose the `.obj` files.
2. Accept the import as MeshParts; set the part Size to the stud size above (or scale per slot), and color with `Color`/`BrickColor`.
3. After upload, send the resulting MeshIds to the lead.
